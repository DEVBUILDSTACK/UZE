## Cross-scheduling model

Team size is flexible (1/3/5+ agents) — what is fixed is the schedule
discipline, owned by the orchestrator front door:

- **One shared routine calendar**, timezone-aware (America/New_York
  default). Every persona's recurring work is a scheduled routine with
  a named slot.
- **No collisions:** two personas never publish to the same handle in
  the same window unless the orchestrator explicitly sequences them
  (e.g., Airwave episode → Vantage LinkedIn cutdown → Bridge partner
  tag — a cross-scheduled chain, not three random posts).
- **Handoff protocol:** when one's output is another's input, the
  handoff is a scheduled, checkable artifact (brief → draft → queued
  post), never a DM that can be missed.
- **Approval gates travel with the schedule:** L3 (publish) items land
  in James's review queue with the scheduled slot attached; a missed
  approval pauses that persona's chain without stopping the others.
