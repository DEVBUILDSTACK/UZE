# Proposal: Ink Ecosystem-Wide Permissionless Builder Program

**Status:** DRAFT for co-author review (2026-10-15)
**Proposers:** James (456 Innovation Partners / UZE), Nithin Mengani, Jonathan Schmidt

## Context

On Sep 14, 2026, sergio (@cruelhandeth) and Kurt (@KurtG) announced they
are building an **@inkonchain ecosystem-wide permissionless builder
program for teams and indie devs looking for funding** — following the
V1 launch of the @Quotrons404 builder registry on Ink. Kurt's call:
serious builders should reach out; the "ink world order" (IWO) has only
just begun.

This proposal answers that call: a concrete program design the three
proposers will build and operate, aligned with Ink and Kraken as Kraken
prepares formal promotion of the ecosystem.

## Vision

A **permissionless** builder program: any team or indie dev can enter
without gatekeepers — entry is by building, funding is by demonstrated
progress. The program serves the whole Ink ecosystem, with a dedicated
track for **frontier NFT security paired with open finance**.

## Why this focus

NFTs on L2s face the same frontier problems as DeFi did in 2020:
provenance fraud, metadata mutability, royalty evasion, and insecure
minting pipelines. Ink — Kraken's OP-Stack L2, built as the house of
DeFi for the Superchain — is where NFT security and open finance must
converge. Frontier NFT security means:

- **Provenance you can prove:** on-chain birth certificates for media
  (Numbers Protocol / ERC-7053 model), verifiable without exposing raw
  assets.
- **Secure minting and custody:** audited patterns for drops, soulbound
  credentials, and creator royalties that actually enforce onchain.
- **Open-finance pairing:** NFT-collateralized lending, fractionalized
  cultural assets, prediction markets on creative output — DeFi
  primitives composed with verifiable media.

## Why Ink

- Ethereum L2 on the OP Stack; 1-second block times (sub-second coming).
- Sequencer-level security protecting users from malicious intents.
- Superchain interoperability: capital flows across the Superchain.
- Kraken's security and crypto expertise behind the chain.
- Live testnet (Ink Sepolia) with faucet; standard Ethereum tooling
  (Foundry, Hardhat, Remix). Ref: https://inkonchain.com/builders,
  https://docs.inkonchain.com/

## Program design (proposed)

**Permissionless entry:** publish a build plan + repo; no application
committee. Onboarding via the Quotrons builder registry pattern.

**Two lanes:**
1. **Teams** — milestone-based funding: prototype → testnet → audit →
   mainnet. Each gate unlocks the next tranche.
2. **Indie devs** — micro-grants for shipped, working demos; fast review
   cycles (weekly), small amounts, high trust.

**Frontier track (flagship):** NFT security × open finance builds get
dedicated review, security-office hours, and audit co-funding. Example
builds: provenance registries, royalty-enforcing marketplaces,
NFT-backed lending, verifiable creator credentials.

**Funding sources (to be confirmed with Ink/Kraken):** ecosystem grants,
Kraken-aligned sponsorship, and programmatic revenue share from
graduated projects. Terms negotiated, not assumed.
