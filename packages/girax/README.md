# packages/girax — GIRAx layer

Artist/creator provenance & IP-protection layer: innovation, attestation, attribution, authentication, affiliate, blockchain.

- KVM3 = the GIRAx on-chain layer (renamed from Assurative.ai architecture), on-chain to physical layer.
- Numbers Protocol provenance (Nid/CID, NFT contract metadata, onchain licenses, royalty distribution) for creator/artist IP fractional licensing and fee attribution.
- Arcium (Solana MPC/MXE) as verifiable execution layer; sealed-bid auctions are the documented MPC use case.
- **Status:** scaffold — MPC-vs-TEE decision still open (decision brief prepared); implementations land with team contributions.
