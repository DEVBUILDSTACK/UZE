# packages/ui — shared design system

Holds the two locked theme systems so every app stays consistent:

1. **UZE primary (Solana ombre):** blue → light blue → green accents; purple boxes for web3 degen cards; bright winter-white text on black glass. GIRA icon always Solana ombre.
2. **Maple institutional (tangerine):** editorial serif headlines, institutional dark sections, tangerine/coral accent — for auction / UZED.si secondary / Preowned / Knowledge Base / dev docs. UZED icon distinct (never Solana-colored): Maple/cream + tangerine ombre. Tangerine-on-purple banned.

White text on black glass = bright winter white, best-practice commerce typography.
