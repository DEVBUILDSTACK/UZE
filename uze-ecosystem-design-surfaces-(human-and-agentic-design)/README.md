# UZE Ecosystem Design Surfaces (Human and Agentic Design)

This folder is the in-repo home and signpost for the UZE ecosystem's two design surfaces:

- **Human Design Surface** — the HUMAN ECOSYSTEM DESIGN: one canonical design source, anchored in every repo, washed before anything ships, resident in white-label engagements by token override only. The engineering anchor lives at the repo root (`DESIGN.md`, `design-wash.json`, `tools/design-gate/`); the canonical tokens live in the design-anchor kit.
- **Agentic Design Surface** — the AGENTIC ECOSYSTEM DESIGN: the design system for non-human actors — MCP-first surfaces, wallet-bound agent identity, gating before execution, the chronicle on every call, settlement per the rail law, and its Fundamental Pillars (agentic trading harnesses and terminals; market reasoning models and data assets; identity, audit trails, and performance-verification infrastructure for non-human financial decision-makers).
